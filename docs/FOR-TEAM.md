# 팀원용: 원정대 브랜드 허브

## 설치 없이 시작
프로젝트의 START.html 파일을 더블클릭하세요. 인터넷이나 Node.js 설치 없이 브라우저에서 열립니다. 팀원에게는 이 파일 하나를 전달해도 됩니다.

첫 화면에서 업무를 선택하세요. Figma 공유 파일이 연결되어 있으면 **공유 Figma 파일 열기**로 이동합니다.
연결 전에는 **Figma 시작하기**에서 담당자의 최초 설정 안내를 확인합니다. 담당자는 생성 도구 ZIP을 실행해 라이브러리를 만든 뒤 파일을 공유합니다.
공유 파일의 `01 Foundations`에서 기준을 확인하고, `02 Components`에서 용도·상태를 고릅니다. `03 Patterns`에서 화면을 복제하거나 Assets에서 컴포넌트를 선택해 문구를 바꿉니다. [자세한 Figma 안내](FIGMA.md).
발표자료 메뉴는 준비 중입니다. 웹 적용은 요청문과 자료 전달 후 프로젝트별 최초 연결이 필요합니다.

1. 브랜드 컬러를 눌러 원하는 색상 코드를 복사합니다.
2. 미리보기에서 라이트·다크 느낌을 확인합니다.
3. AI 적용 요청에서 작업 이름·종류·테마를 선택합니다.
4. 요청문을 복사하고 브랜드 자료 ZIP을 받습니다.
5. 사용 중인 AI에 요청문과 ZIP을 함께 전달하고, 작업할 프로젝트/문서를 지정합니다.

자동 복사가 제한되면 선택된 텍스트를 Ctrl+C(맥은 Cmd+C) 또는 길게 눌러 복사합니다. ZIP 첨부를 지원하지 않는 AI에는 압축을 풀어 안내 문서와 JSON을 전달합니다.

## 함께 쓰는 방법
- **사용자:** 공통 기준을 확인하고 AI에 적용을 요청합니다. 팀 기준 자체를 임의 변경하지 않습니다.
- **제안자:** 의견을 작성해 GitHub 작성화면에서 등록하거나, 의견을 복사해 담당자에게 전달합니다. 허브에서 외부로 자동 전송하지 않습니다.
- **브랜드 담당자:** 의견을 검토해 원본 규칙 수정 여부를 결정합니다.
- **관리 담당자:** 변경 사항을 레포에 반영하고 검사 후 새 버전의 START.html을 배포합니다.

이 버전은 공유 배포본이며 실시간 공동 편집기가 아닙니다. 다른 팀원의 변경이나 중앙 레포 수정이 이미 받은 HTML에 자동 반영되지는 않습니다. 팀은 같은 버전 파일을 함께 사용하세요.
GitHub 레포가 비공개라면 팀원 초대가 필요합니다. GitHub 계정이 없는 팀원도 HTML·ZIP과 의견 복사 기능은 사용할 수 있습니다.

## 현재 가능한 것과 남은 것
가능: 색상 복사, 두 테마 미리보기, 작업별 요청문, 오프라인 ZIP, 의견 초안, 로그인 없는 자료 열람.
추가 구현 필요: 실시간 댓글/공동 편집, 역할별 승인 UI, 자동 업데이트, Figma/브라우저 확장, Windows 설치 프로그램.
정식 로고·폰트·사진 원본은 별도로 제공받아야 합니다.
