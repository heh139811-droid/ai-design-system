공유 Figma 파일이 아직 연결되지 않았습니다. 담당자가 아래 생성 도구를 한 번 실행하고 파일을 공유해야 합니다.

색상은 브랜드 원본 기준이며 글꼴·간격·라운드·컴포넌트는 구현 제안입니다. 공식 Figma 연동이나 자동 동기화 기능은 아닙니다.

담당자: 라이브러리 최초 생성·공유하기
  1. 아래 ZIP을 받고 압축을 풉니다.
  2. Figma 데스크톱에서 빈 Design 파일을 열고 Plugins → Development → Import plugin from manifest로 manifest.json을 등록합니다.
  3. 개발 메뉴에서 ‘원정대 기본 라이브러리 생성’을 실행합니다.
  4. 생성 결과를 검토한 뒤 파일을 공유하거나 팀 라이브러리로 게시합니다. 게시 가능 여부는 조직의 플랜과 권한에 따라 다릅니다.
  5. 관리 담당자가 허브에 공유 주소를 연결하고 새 배포본을 전달합니다.

생성 도구에는 네트워크 접근이 없습니다. 같은 버전 재실행은 기존 페이지를 엽니다. 자세한 안내와 검증 한계는 ZIP의 README.md에서 확인하세요.

요청문과 ZIP을 사용 중인 AI에 함께 전달하세요. 레포를 열 수 없는 AI도 첨부 자료를 참고할 수 있습니다.

복사한 뒤에는 어떻게 하나요?
  1. 자료 ZIP을 다운로드하고, 사용 중인 AI 도구에 첨부합니다. ZIP 첨부가 안 되면 압축을 풀어 안내 문서와 색상 JSON을 전달합니다.
  2. 복사한 적용 요청을 붙여넣고 작업할 프로젝트나 파일을 지정합니다.
  3. AI가 적용한 결과를 확인합니다. 기존 사이트는 처음 한 번 스타일 연결 작업이 필요합니다.
